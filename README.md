## Установка и запуск

### 1. Клонирование / копирование файлов

Скопируйте всю папку `manicure_bot/` на ваш сервер или ПК.

### 2. Создание виртуального окружения

```bash
cd manicure_bot
python3 -m venv venv
source venv/bin/activate      # Linux / macOS
# venv\Scripts\activate       # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации

**Способ A — через переменные окружения (рекомендуется):**

```bash
cp .env.example .env
# Откройте .env и заполните значения
```

Затем в `config.py` замените строки на чтение из `.env`:
```python
from dotenv import load_dotenv
load_dotenv()
```
И установите `pip install python-dotenv`.

**Способ B — напрямую в `config.py`:**

Откройте `config.py` и замените значения по умолчанию:
```python
BOT_TOKEN = "ВАШ_ТОКЕН"
ADMIN_ID  = 123456789      # ваш Telegram ID
CHANNEL_ID   = "@your_channel"
CHANNEL_LINK = "https://t.me/your_channel"
```

> **Как узнать свой Telegram ID?** Напишите боту [@userinfobot](https://t.me/userinfobot).

### 5. Настройка каналов

- **CHANNEL_ID** — ID канала, куда бот будет публиковать расписание после каждой записи/отмены. Бот должен быть **администратором** этого канала.
- Для проверки подписки бот также должен быть администратором канала (или хотя бы участником с правом получать список участников).

### 6. Запуск бота

```bash
python bot.py
```

---

## Первые шаги после запуска

1. Напишите боту `/start` — убедитесь, что появляется меню.
2. Напишите `/admin` с аккаунта администратора.
3. Через админ-панель добавьте рабочий день (кнопка **➕ Добавить рабочий день**).
4. Добавьте временны́е слоты на этот день (кнопка **🕐 Добавить слот**).
5. Протестируйте запись через обычный аккаунт.

## Возможности бота

### Клиент
| Функция | Описание |
|---|---|
| 📅 Записаться | Выбор даты → времени → имя → телефон → подтверждение |
| ❌ Отменить запись | Отмена активной записи с освобождением слота |
| 💅 Прайсы | HTML-список услуг |
| 🖼 Портфолио | Ссылка на Pinterest |
| ⏰ Напоминание | Автоматически за 24 ч до визита |

### Администратор (`/admin`)
| Функция | Описание |
|---|---|
| ➕ Добавить рабочий день | Дата в формате YYYY-MM-DD, до 31 дня вперёд |
| 🕐 Добавить слот | Время HH:MM на выбранный день |
| 🗑 Удалить слот | Удаление слота (с отменой записи, если занят) |
| 🚫 Закрыть/открыть день | Переключение доступности дня |
| ❌ Отменить запись клиента | Выбор слота и отмена с уведомлением клиента |
| 📋 Просмотр расписания | Полное расписание на выбранный день |

---

## Ограничения
- Один пользователь — одна активная запись
- Расписание формируется максимум на 31 день вперёд
- Напоминание не создаётся, если до визита менее 24 часов
- Доступ к `/admin` только для `ADMIN_ID`
